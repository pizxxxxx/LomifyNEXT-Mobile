# Проверка мобильных исправлений 1.0.33

Область: напоминание об обновлении, запуск выбранного трека, кнопки полного
плеера, переход обложки в текст, haptics и конверт внешнего поиска по словам.
Использованы рекомендации better-ui; сохранены тема, шрифт и настройки движения.

| Область | Изменение | Проверка |
| --- | --- | --- |
| Обновления | Нативный dialog с текущей и новой версией, «Скачать» и «Позже» | WebKit, iOS/Android состояния; 320 px без переполнения; Escape; ошибка открытия сохраняет возможность повторить |
| Момент показа | После отрисовки, без перехвата открытого меню, ввода и полного плеера | Проверка условий и сценарий открытого меню; нет окна при current/error |
| Движение | transform/opacity, короткий выход, системное reduced motion и настройка приложения | Регрессионные тесты движения; CSS-проверка отключения анимации |
| Значки | Прозрачные кнопки плеера используют один набор компактных SVG в обоих режимах | 320 px: основной glyph 43 px внутри 76 px; соседние 30 px внутри 44 px; вспомогательные 23 px внутри 44 px |
| Видео и текст | Обложка увеличивается и исчезает за 620 мс, при закрытии возвращается | WebKit: opacity обложки 0, video opacity 1, readyState 4; ширина документа 320 px |
| Воспроизведение | Остановка старого источника сохраняет play intent | Реальный Player в WebKit со стендовым нативным gate: нажатие Волны даёт playing=true, blocked=false; Rust-тесты звонков и отключения выхода проходят |
| Haptics | Системный отклик намеренных действий, без прокрутки и дубля UIKit | Тесты делегирования, первой отдачи, частоты, disabled и очистки; обе production-сборки |
| По словам | collection/has_more для lyrics, items для vibe | Тест ответа с найденной строкой и конца пагинации |

Проверены Svelte/TypeScript (0 errors, 0 warnings), тесты обновлений, удержания,
haptics, поиска, движения, мобильного idle, волны, очереди и видео; 5 iOS и 4
Android теста состояния паузы. В пакетах APK и IPA сверены все 23 встроенных
JS/CSS-ресурса с соответствующей production-сборкой.

Напоминание проверяет публичные релизы GitHub при холодном запуске. Возврат из
фона использует шестичасовой кэш; ручная проверка обновляет его. «Позже» действует
до следующего запуска процесса приложения; новая версия может появиться раньше.
При ошибке сети всплывающего окна нет, повторная проверка доступна в настройках.
На iOS открывается страница с IPA; на Android — APK. Токены музыкальных сервисов
не отправляются в запросах обновлений.

На физических телефонах эта версия, сила тактильного отклика, реальная частота
кадров и вход/поиск с настоящим аккаунтом scnative ещё не проверены. Стенд использует
вымышленные треки и тестовую следующую версию. VoiceOver/TalkBack не проверены.
Approve — только для описанного покрытия; гарантия 120 Hz не заявляется.
