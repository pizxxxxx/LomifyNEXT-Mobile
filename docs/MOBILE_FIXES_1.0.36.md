# Проверки исправлений 1.0.36

При отпускании пальца `mobileSwipeDismiss` задавал translate сразу на высоту
экрана, а затем запускал Svelte outro. CSS одновременно выполнял отдельный
переход translate за 180 мс. Получались два владельца движения, а расчёт
оставшегося пути видел уже конечную координату.

Теперь действие сохраняет смещение под пальцем и передаёт скорость отпускания.
Один Svelte outro проходит оставшийся путь. Скорость усредняется по короткому
окну событий; удержание пальца гасит инерцию. Монотонная кубическая траектория
согласует начальную скорость с жестом и тормозит до нуля у нижнего края.
Длительность выхода после свайпа ограничена 280–500 мс. Обычное нажатие
сохраняет прежние 480 мс. Возврат отменённого свайпа занимает 280 мс.

Фабрика перехода возвращает отложенную конфигурацию: фактические направление,
смещение и скорость читаются при запуске конкретного intro/outro, включая
переходы Svelte с направлением `both`. Ожидание нативных кнопок UIKit привязано
к полной длительности выхода; во время движения используется поверхность DOM.
При выключенных анимациях длительность равна нулю.

`node scripts/mobile-swipe-dismiss-test.mjs` проверяет короткий бросок 80 px,
сохранение позиции вместо скачка к высоте экрана, оставшийся путь, начальную
и конечную скорость, отсутствие обратного хода и перелёта при разных скоростях,
долгий/медленный/удержанный свайп, pointercancel, lostpointercapture, исключение
текста и интерактивных кнопок, обычное нажатие, уменьшение движения и очистку.
`node scripts/mobile-idle-test.mjs` проверяет передачу кнопок UIKit на WebKit
без постоянного измерения координат. `node scripts/mobile-navigation-test.mjs`
проверяет существующие жесты назад и историю.

На стенде с настоящим Svelte-плеером и WebKit, ширина 320 px, высота 696 px:
после броска на 80 px выход начинался с transform 0 поверх сохранённого
translate 80 px, проходил оставшиеся 616 px за 440 мс и завершался удалением
панели. Удержание такого же свайпа возвращало translate к 0 и оставляло плеер
открытым. После отмены обычное нажатие закрывало панель за 480 мс на весь путь
696 px. Проверки TypeScript/Svelte прошли без ошибок и предупреждений.

Production-сборки Android ARM64 и iOS ARM64 прошли. Все 23 JS/CSS-ресурса
финальной frontend-сборки сверены с бинарными файлами внутри APK и IPA.
APK: версия 1.0.36, versionCode 9010029, прежний сертификат SHA-256
`05646e3ba6891a351bd5b4afe58d66a590ad673819fb4a24e580ed81c67f6dad`,
выравнивание 16 KB. IPA: версия 1.0.36, build 10029, ARM64, iOS 15+, режим
фонового аудио. Проверено отсутствие `.env` и персонального provisioning
profile. Проверки текущих и старых клиентов для общего релиза проходят.
Контрольные суммы пакетов приложены к релизу.

На физическом iPhone плавность нового перехода пока не проверена. Время кадра
стенда не гарантирует частоту кадров и ощущения на телефоне пользователя.
