# Обновления мобильной версии через GitHub

Начиная с Android `1.0.0-beta.2`, приложение проверяет [релизы LomifyNEXT-Mobile](https://github.com/pizxxxxx/LomifyNEXT-Mobile/releases) при запуске и после возвращения из фона. Проверка не задерживает открытие плеера. Повторный автоматический запрос выполняется не чаще одного раза в 6 часов; кнопка «Проверить сейчас» в настройках обходит этот интервал.

Если найден APK новее установленного, на главной появляется сообщение, а в настройках - кнопка «Скачать APK». Приложение передаёт ссылку системному браузеру. После загрузки пользователь открывает APK и подтверждает установку в Android. Тихая установка не выполняется. На iPhone отдельная кнопка открывает последний IPA-релиз для установки через AltStore; Android-проверка такие релизы пропускает.

## Как опубликовать следующую Android-сборку

1. Перед сборкой увеличьте версию во всех местах из раздела 10 `PROJECT_MAP.md` и `bundle.android.versionCode` в `src-tauri/tauri.conf.json`. Для обновления установленного APK новый `versionCode` должен быть больше прежнего.
2. Соберите ARM64 APK и подпишите его **тем же ключом**, которым подписана предыдущая установленная версия. Если ключ не совпадёт, Android не установит обновление поверх приложения. Не загружайте файл ключа или пароль на GitHub.
3. Назовите файл строго `LomifyNEXT-<версия>-arm64.apk`, например `LomifyNEXT-1.0.0-beta.3-arm64.apk`. Версия в имени должна совпадать с версией внутри APK.
4. На GitHub откройте `pizxxxxx/LomifyNEXT-Mobile` > `Releases` > `Draft a new release`. Создайте тег той же версии, добавьте описание изменений, прикрепите APK через `Attach binaries` и нажмите `Publish release`. Для бета-версии отметьте `Set as a pre-release`.
5. На телефоне с предыдущей версией откройте приложение или в `Настройки` > `Обновления` нажмите `Проверить сейчас`. Должны появиться номер новой версии и кнопка загрузки.

Проверка сравнивает версию **файла APK**, даже если тег релиза отличается. Например, первый релиз имел тег `v1.0.0`, а файл назывался `1.0.0-beta.1`. Первую установку на устройство со старой `beta.1` без функции проверки придётся выполнить вручную.

Исходники публикуются в ветке `main` репозитория `pizxxxxx/LomifyNEXT-Mobile`. Описание релиза 1.0.12 хранится в `docs/releases/v1.0.12.md` и включает все изменения после 1.0.10: промежуточная 1.0.11 отдельно не выпускалась.

Проверка использует только публичный API GitHub и не передаёт токены музыкальных сервисов. Если сети нет или GitHub ограничил запросы, музыка продолжает работать, а в настройках появляется возможность повторить проверку.
