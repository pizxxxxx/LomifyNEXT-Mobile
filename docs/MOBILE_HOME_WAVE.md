# Карточка станции на главной — 1.0.30

Область: вход в «Мою Волну» / «Мою Тусню» на главной iOS и Android,
включая загрузку, ошибку и пустую ленту. Svelte 5, общий `src/mobile.css`,
существующие мобильные токены и Onest / выбранный пользователем шрифт.
Прочитаны `MOBILE_UI.md` и `MOBILE_WAVE.md`; AGENTS.md не найден.
Десктопный WaveHero и экран открытой станции в эту переработку не входят.

## План до реализации

Использованы frontend-design и better-interface с шестью доменными skills.
В [разборе NN/g](https://www.nngroup.com/articles/characteristics-minimalism/)
важен принцип удаления оформления, которое не помогает задаче, при сохранении
понятных действий. Рассмотрены официальные страницы
[Яндекс Музыки](https://music.yandex.ru/) и [Apple Music](https://www.apple.com/apple-music/).
Задача карточки Lomify — быстро запустить личную станцию рядом с медиатекой.

- Палитра из существующих токенов: фон `#0b0b0e`, поверхность `#19191e`,
  поднятая поверхность `#2a2a30`, текст `#f5f5f7`, подписи `#b2b2be`.
- Название 22/600, источник 13/400; при крупном тексте — 25 и 15.
  Шрифт наследуется, новых семейств и загрузок нет.
- Название и источник слева, небольшой рисунок волны с Play справа.
  Вся карточка — одна кнопка; Play не вложенная кнопка и не отдельный hit area.
- Общая поверхность и радиус 12 px, без индивидуальной цветной рамки,
  градиентного значка, рекламного слогана и декоративных служебных подписей.
- Один музыкальный мотив: три собственные SVG-линии. Они статичны,
  без таймера, фоновой анимации, blur и новых зависимостей.

План пересмотрен против запроса: вместо нового яркого hero используем
масштаб и края существующих элементов главной. Выразительность остаётся
у музыкальных обложек; карточка станции помогает начать слушать.

## Verification

Passed:

- `LOMIFY_ENV_DIR=src-tauri/target/ios-empty-env npm run check`: 0 ошибок,
  0 предупреждений. Каталог переменных окружения пустой; `.env` не читается.
- `node scripts/mobile-features-test.mjs`: запуск SoundCloud из любимых,
  очередь, отмена позднего запуска и сохранение других источников.
- `node scripts/mobile-version.mjs --check`: 1.0.30, iOS 10023,
  Android 9010023.
- Реальный MobileApp в WebKit с изолированными тестовыми ответами:
  загрузка, ошибка и пустая лента на трёх размерах; крупный текст на 320×568.
  Карточка не исчезает вместе с лентой и не расширяет экран.
- Фокус через Tab/Shift+Tab — 2 px с отступом 3 px. Enter открывает
  Яндекс-станцию и запускает её один раз (`starts=1`, `playing=true`).
  Без аккаунта открывается подключение, запуска нет (`starts=0`).
- Android-режим превью: SoundCloud / «Моя Тусня», нажатие открывает
  станцию из любимых с воспроизведением. Настоящие аккаунты не используются.
- Цвета измерены на фактическом фоне `rgb(25,25,30)`;
  декоративные линии не несут состояния и не нужны для чтения.
- Итоговый снимок: `src-tauri/target/ui-1.0.30-home.jpg`.
- Собраны production ARM64 APK и device IPA; в каждом архиве подтверждены
  все 23 JS/CSS-файла его интерфейса. Сертификат APK совпадает с исходным
  Android-ключом; zipalign 16 КБ проходит. IPA: iPhoneOS, iOS 15+,
  версия 1.0.30 (10023), без персонального профиля и файлов `.env`.

Not verified: VoiceOver/TalkBack, настоящий browser zoom 200%, RTL,
все пользовательские шрифты и темы, касания и звук на физическом телефоне.
Новых постоянных анимаций на карточке нет; общий reduced motion сохранён.
