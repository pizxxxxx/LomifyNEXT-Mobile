# Переходы плеера и коллекций 1.0.27

План по `frontend-design` и `better-ui`: сохранить музыкальный интерфейс,
выбранные пользователем шрифты и плотность списка. База `#101014`, поверхность
`#1c1c23`, текст `#f5f5f7`, вторичный текст `#b2b2be`, акцент `#ff884d`
из существующих переменных, с настройками текущей темы.
Обложка — единственный крупный движущийся элемент. В плейлисте она переходит
с карточки в квадратную шапку до 224 px, под ней центрированные название
26/700 и счётчик треков; список остаётся плотным и виртуализированным.
«Любимые треки» получают ту же композицию со своим существующим сердцем
и цветом. Проверка плана: переход связан с выбранной коллекцией, служебная
карточка синхронизации входит вместе с содержимым; новых украшений нет.

Веб-кнопки плеера подогнаны по размерам к нативным. Смена прозрачности
при передаче управления UIKit не анимируется и не запускает новый цикл
передачи. Положение измеряется после остановки; никаких обещаний 120 FPS
эта схема сама по себе не даёт.

Passed:

- Svelte/TypeScript: 0 ошибок и предупреждений.
- Проверка моста: 600 событий движения плеера без потока координат и без
  повторяющегося RAF; нативные кнопки возвращаются после остановки.
  Изменение opacity не запускает очередную передачу. Существующие проверки
  600 событий скролла артиста без геометрии, диалогов и очистки моста проходят.
- Проверки перехода коллекций: координаты карточки/шапки, остановка старого
  перехода, уход до первого кадра, неизменившиеся данные и reduced motion.
- Проверки навигации, функций коллекций и SoundCloud проходят.
- WebKit: открытие и закрытие плеера, текст и обратный переход, быстрые
  переключения. После исправления focusout основной экран возвращается
  без inert, повторная проверка консоли без ошибок.
- Видео из локального тестового файла играет под текстом; у обложки после
  перехода opacity 0 и blur 12 px, у затемнения opacity .78. Живые аккаунты
  и запросы за видео Яндекса для этой проверки не использовались.
- Плейлист и любимые проверены при 402×874 и 320×568 без горизонтального
  переполнения; виртуализированный список остаётся ограниченным viewport.
- Движение обложки плейлиста просмотрено в тестовом WebKit при playbackRate
  0.1; вступление 560 ms и отдельные этапы 420 ms подтверждены по Animation.
  Тестовый замедлитель и видео находятся в игнорируемом target и не входят в IPA.

Not verified: FPS, температура и расход энергии физического iPhone,
визуальная смена веб-кнопок на UIKit на устройстве, реальные видео Яндекса,
VoiceOver и панель Animations DevTools. Замедленная проверка выполнена
через тестовый Animation playbackRate, а не через эту панель.

Approve — для проверенных сценариев, без подтверждения FPS на телефоне.
