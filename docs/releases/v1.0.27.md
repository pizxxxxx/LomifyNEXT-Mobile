# LomifyNEXT iOS 1.0.27 beta

2 октября 2026 года, ветка `ios`, iOS build 10020.

Исправлен источник рассогласования кнопок и поверхности большого плеера:
во время движения больше не читаются и не пересылаются координаты UIKit
каждый кадр. На время перехода видны существующие веб-кнопки, которые
двигаются вместе с плеером; после остановки возвращаются нативные UIKit.
Их размеры согласованы. Переход плеера использует только translate3d,
а загрузка видео начинается после его вступления.

Исправлена ошибка Svelte при закрытии экрана: обработчик фокуса больше
не меняет состояние синхронно во время удаления элементов.

Плейлисты, включая «Любимые треки», получили одинаковую крупную шапку:
обложка переходит с карточки в шапку за 560 мс, название и треки появляются
отдельно. Возврат и быстрое прерывание перехода учитываются. Список остаётся
виртуализированным, функции плейлистов и любимых сохранены.

При открытии текста обложка увеличивается, плавно размывается до 12 px и
исчезает, открывая видеофон. Затемнение становится мягче. При закрытии
текста обложка возвращается. Для треков без видео остаётся фон обложки/темы.
Пауза, отключённый видеофон и reduced motion сохраняют прежние ограничения.

Svelte/TypeScript, проверки моста, движения, навигации и коллекций проходят.
WebKit: плеер, текст с тестовым видео, оба типа коллекций, возврат и быстрые
переключения; 402×874 и 320×568 без горизонтального переполнения. Обложка
просмотрена при 10% скорости. На физическом iPhone FPS и визуальная смена
кнопок на UIKit ещё не проверены. [Разбор проверок](../IOS_MOTION_1.0.27.md).

Автозапуск волны 1.0.26 и кнопка проверки обновлений 1.0.25 сохранены.
[Установка через AltStore](../IOS_ALTSTORE.md).

Device IPA для ARM64 iPhone собрана под Xcode 27: версия 1.0.27,
build 10020, bundle ID `io.github.pizxxxxx.lomifynext.mobile`, минимум iOS 15.
Обновлённый мост, переходы коллекций, blur/opacity обложки и версия
подтверждены по байтам ассетов внутри нативного бинарника.

IPA: `src-tauri/target/ios-dist/LomifyNEXT-1.0.27.ipa`, 21 701 421 байт.
SHA-256: `11ee4f097fea917d6f3285d32b5b1ea1b3e438c7fddfc67982d33e444325511f`.
Без личной подписи и provisioning profile; AltStore подписывает при установке.
Файлов `.env`, тестового видео и внешних `ffmpeg`/`ffprobe` внутри нет.

Отдельный iOS prerelease с IPA из ветки `ios`, без назначения Latest и без APK.
`main` и Android-релиз остаются прежними.
