# LomifyNEXT Mobile 1.0.34 — Android и iOS

- Исправлены лайки в «Моей Волне»: составной ID Яндекса и смена названия трека больше не сбивают отметку. Быстрые повторные нажатия не теряются при синхронизации.
- Видеофон под текстом сохраняет плеер и готовый кадр при паузе и обновлении данных. При продолжении воспроизведение видео возобновляется.
- Подготовленная очередь и получение ссылки на следующий трек перенесены на нативную сторону. Ссылки обновляются перед запуском; сворачивание не очищает очередь. Отмена загрузки не позволяет старому запросу позднее запустить трек.
- При временном отказе скачивания ссылка обновляется один раз. Исправлено распознавание HLS без расширения в URL; нехватка места и ошибки доступа показываются отдельно.
- Стабилизирована геометрия шапки плеера при открытии текста, чтобы уменьшить скачки во время приближения обложки.

**Android:** `LomifyNEXT-1.0.34-arm64.apk`, Android 8+, ARM64. Подписан прежним
ключом и устанавливается поверх совместимой предыдущей версии с сохранением
данных. Ранняя тестовая 1.0.28 с другим сертификатом остаётся отдельной установкой.

**iPhone:** `LomifyNEXT-1.0.34.ipa`, iOS 15+, ARM64 для устройства. Сохранить IPA
в «Файлы», затем AltStore Classic → My Apps → «+» с тем же Apple ID. Подпись
добавляет AltStore. Для обновления выберите новую IPA; Refresh All только
продлевает подпись уже установленной версии.

Один общий релиз с APK и IPA. Тег `ios-v1.0.34` совместим с кнопкой обновления
старых iOS 1.0.25–1.0.27; Android выбирает APK на той же странице.

Сборки и автоматические проверки прошли. Видеофон и размеры кнопок проверены
на стенде WebKit с шириной 320 px. На физических телефонах версия ещё не
проверена; стабильные 120 кадров/с и бесконечная работа Волны при постоянно
спящем интерфейсе не подтверждены.
