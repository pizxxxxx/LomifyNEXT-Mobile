# LomifyNEXT Mobile 1.0.35 — Android и iOS

- Убраны полноэкранный дубль обложки и заставка видео, из-за которых поверх видео под текстом появлялась огромная статичная картинка. Основная обложка по-прежнему приближается и плавно исчезает при открытии текста, а при закрытии возвращается.
- Видеофон плавно появляется после первого готового кадра. Слои видео, затемнения и содержимого имеют явный порядок. После неожиданной паузы WebKit видео получает одну попытку продолжения; обычная пауза сохраняет кадр.
- Отключено браузерное увеличение страницы щипком и двойным касанием. В iOS дополнительно отключён нативный жест увеличения WebView. Прокрутка, ползунки и свайпы остаются доступны.

**Android:** `LomifyNEXT-1.0.35-arm64.apk`, Android 8+, ARM64, прежний ключ подписи.

**iPhone:** `LomifyNEXT-1.0.35.ipa`, iOS 15+, ARM64. Установка через AltStore Classic → My Apps → «+» с тем же Apple ID. Refresh All продлевает подпись уже установленной версии; для обновления выберите новую IPA.

Общий релиз с APK и IPA; кнопки обновления старых iOS находят тег `ios-v1.0.35`.

Сборки, проверки TypeScript/Svelte, тесты видеоплеера и переходов прошли. Фон проверен на стенде WebKit при ширине 320 px. На физическом iPhone запрет жеста увеличения и воспроизведение видео ещё не проверены.
