# LomifyNEXT Mobile 1.0.32 — Android и iOS

Обновлены поиск, меню трека и навигация:

- «Моя Волна» стала отдельной первой вкладкой. «Главное» объединяет поиск, любимое, историю и рекомендации.
- Поиск разворачивается и сворачивается с переходом; вкладки движутся влево или вправо по порядку нижней панели.
- В меню трека Яндекса добавлена «Моя Волна по треку»: сразу запускает станцию, показывает название сверху; крестик возвращает обычную волну.
- Меню трека стало спокойнее: нейтральный фон, обложка, круглые быстрые действия и понятные строки команд.
- Добавлены подсказки поиска и «Недавно слушал», включая историю Яндекса.
- Поиск по коллекции учитывает опечатки, порядок слов, транслит и раскладку. Каталог при пустой выдаче пробует другую раскладку в том же сервисе.
- В «Настроении» можно выбрать Яндекс: спокойное, бодрое, весёлое или грустное. Отдельная сессия подбирает треки без изменения основной волны.
- Экспериментальный поиск по словам и описанию настроения в SoundCloud использует внешний индекс. Найденная строка показывается прямо на обложке.
- Переходы вкладок и меню начинаются после отрисовки содержимого. Скрытая вкладка волны не обновляет визуализатор и строки песни.

**Поиск по словам и описанию настроения в SoundCloud:** нужен отдельный вход через кнопку SoundCloud.
Они ищут в коллекции стороннего сервиса scnative.space. Реальный адрес входа
проверен; поиск с авторизованным аккаунтом и завершение входа на телефоне ещё не
проверены. Основной поиск Яндекса и SoundCloud работает независимо от этого входа.
Яндекс в «Настроении» использует уже подключённый аккаунт и четыре параметра
рекомендательного API. Свободное описание через «Люмена» пока не подключено:
подтверждённого метода его вызова не найдено. Подбор с настоящим аккаунтом ещё
не проверен; тесты проверяют запросы, формы ответов и отмену.

**Android:** скачать `LomifyNEXT-1.0.32-arm64.apk` и установить поверх старой версии.
Сохранён прежний ключ подписи; удалять приложение не требуется. Android 8+, ARM64.
Ранняя тестовая APK 1.0.28 с другим сертификатом остаётся отдельной установкой.

**iPhone:** скачать `LomifyNEXT-1.0.32.ipa`, сохранить в «Файлы», затем AltStore Classic
→ My Apps → «+» с тем же Apple ID. IPA для устройства, минимум iOS 15, подпись добавляет
AltStore. Refresh All продлевает подпись, а новая версия устанавливается через «+».

APK и IPA в одном релизе. Технический тег `ios-v1.0.32` поддерживает кнопку обновления
старых iOS 1.0.25–1.0.27; Android выбирает APK с той же страницы.

Проверены Svelte/TypeScript, регрессионные тесты, переходы и карточки в WebKit,
production-сборки обеих платформ, версия и сертификат APK, содержимое IPA.
На физических телефонах эта версия ещё не проверена; 120 Hz не заявляются.
