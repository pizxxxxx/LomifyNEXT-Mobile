# LomifyNEXT Mobile 1.0.17

- Длинные ошибки и сообщения загрузки больше не расширяют полноэкранный плеер на Android и iOS. Длинные адреса переносятся, очень длинную ошибку можно прокрутить отдельно.
- Кнопки плеера помещаются на узких экранах: область текста песни подстраивается под оставшееся место.
- На паузе убраны повторные обновления неизменной позиции. Мост UIKit пропускает изменения обычного списка и сохраняет цвет кнопок между обновлениями.
- Строки треков уменьшены с 88 до 72 пикселей, сокращены отступы медиатеки; необязательный параллакс игнорирует дрожь датчика и отключает слушатель на страницах без объёмных панелей.
- У любимых треков яркое белое сердце на насыщенной обложке с выбранным цветовым акцентом.
- Исправлено зависание переключения вкладок после большого импорта Яндекса. Медиатека сохраняется через IndexedDB, если localStorage заполнен.
- Добавлена версия для iPhone с встроенным декодированием и обработкой аудио для установки через AltStore. На iOS 26+ используются нативные панели и круглые кнопки UIKit Liquid Glass. Плеер сворачивается свайпом вниз по верхней части; иконки стали тоньше.

Версия npm, Cargo, Tauri и интерфейса: 1.0.17. Android versionCode: 9010010. iOS build: 10010.

Проверка раскладки выполнена в WebKit с настоящими стилями приложения на 280×568, 320×568, 360×640, 390×844 и 640×360: загрузка, длинная ошибка, адрес без пробелов и отсутствие ошибки. Во всех 20 случаях содержимое и кнопки помещаются по ширине; длинные ошибки прокручиваются отдельно. До исправления содержимое плеера на экране 320 пикселей растягивалось до 640. Проверки сохранения большой медиатеки и обложек проходят, svelte-check сообщает 0 ошибок и 0 предупреждений. Device IPA, симулятор iOS и Android APK собираются. Проверка этой версии на физических телефонах ожидает владельцев.

IPA: `src-tauri/target/ios-dist/LomifyNEXT-1.0.17.ipa`. Устанавливать через AltStore поверх прежней версии с тем же Apple ID. Подробности: [IOS_ALTSTORE.md](../IOS_ALTSTORE.md).

Android release APK без подписи: `src-tauri/target/android-dist/LomifyNEXT-1.0.17-arm64-unsigned.apk` (27 333 781 байт). APK для отдельной тестовой установки: `src-tauri/target/android-dist/LomifyNEXT-1.0.17-debug.apk` (53 873 329 байт). Release APK проходит проверку выравнивания для страниц 16 КиБ; обновлённые стили подтверждены внутри нативных бинарников IPA и release APK.

Для Android обновление поверх опубликованной 1.0.16 требует её прежний ключ. Сертификат опубликованного APK: SHA-256 `05646e3ba6891a351bd5b4afe58d66a590ad673819fb4a24e580ed81c67f6dad`. Местный debug-ключ этого Mac отличается; сборка с ним предназначена для отдельной тестовой установки. Не удаляйте установленное приложение ради несовпадающей подписи.

Изменения остаются локально в ветке `ios`; релиз и исходники на GitHub не опубликованы.

Проверки оптимизации и компактных списков: [MOBILE_PERFORMANCE.md](../MOBILE_PERFORMANCE.md). Проверка нагрева физического телефона после обновления ещё требуется.
