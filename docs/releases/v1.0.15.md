# LomifyNEXT Mobile 1.0.15

Изменения после 1.0.14.

- Исправлен перенос текста песни с подсветкой по буквам. Короткие слова вроде «ей», «ещё» и «неё» больше не распадаются, когда могут поместиться на строке целиком.
- Сохранены расстояния между буквами выбранного шрифта. Режимы по буквам и по строкам одинаково размещают текст.
- Очень длинные слова переносятся без обрезания на узком экране.

APK для Android ARM64, Android 8.0 и новее. Обновление устанавливается поверх предыдущей версии с сохранением данных.

Проверено на синтетическом тексте в браузере при ширине 320 и 375 пикселей, с обычным и крупным текстом и четырьмя шрифтами. Проверка на настоящем телефоне пока не проводилась.
