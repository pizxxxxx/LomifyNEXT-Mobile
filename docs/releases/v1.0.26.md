# LomifyNEXT iOS 1.0.26 beta

2 октября 2026 года, ветка `ios`, iOS build 10019.

Нажатие на карточку «Моя Волна» / «Моя Тусня» на главной теперь открывает
станцию и запускает музыку, без второго нажатия в центре экрана. Запрос
начинается после первого отображения страницы; звук включается, когда
сервис отдаёт трек. Длительность загрузки зависит от сети и сервиса.

Если станция уже играет, открытие сохраняет текущий трек и очередь.
Если она на паузе, карточка возобновляет её. Обычный возврат через историю
не запускает музыку сам. Автозапуск запрашивается только нажатием карточки
и используется один раз. Без входа в Яндекс остаётся экран подключения;
сетевой запрос на запуск не отправляется.

Уход со страницы и отмена загрузки отменяют ещё не завершённый запуск.
Поздний ответ SoundCloud также пропускается после смены источника,
ручного выбора другого трека или нового запуска станции. Уже начавшая
играть волна продолжает звучать после перехода в другой раздел.
Пауза, фильтры и «Собрать заново» сохраняют своё поведение.

Проверки Svelte/TypeScript: 0 ошибок и предупреждений. Сценарии
SoundCloud с отложенным ответом, отменой, сменой трека/источника и двумя
одновременными запросами проходят. Проверки Яндекс-волны, реакции SVG
на музыку и движения интерфейса также проходят.

В WebKit проверены реальные мобильные компоненты: первое нажатие,
повторное открытие, возобновление паузы, возврат через историю без запуска,
медленная загрузка с уходом назад, ошибка с повторной попыткой и отсутствие
входа в Яндекс. Яндекс-ответ и аудио в проверке тестовые, без аккаунта.
SoundCloud запускается из тестовых любимых треков, сохраняет трек и очередь
при повторном открытии. Экран 402×874 без горизонтального переполнения.
Прослушивание этого изменения на физическом iPhone ещё не проверено.

Кнопка «Проверить обновление» из 1.0.25 и исправления анимаций/аудио
из 1.0.24 сохранены. [Установка через AltStore](../IOS_ALTSTORE.md).

Device IPA для ARM64 iPhone собрана под Xcode 27. Версия 1.0.26,
номер сборки 10019, bundle ID `io.github.pizxxxxx.lomifynext.mobile`,
минимальная iOS 15. Автозапуск, версия и сохранённый переход обложки
620 мс подтверждены по байтам ассетов в нативном бинарнике.

IPA: `src-tauri/target/ios-dist/LomifyNEXT-1.0.26.ipa`, 21 699 550 байт.
SHA-256: `bb1f8ffd4a4dc0ef58f71ba4b77d20ce6bfd3f23beab97412f5c3c9c2fec8836`.
Архив без личной подписи и provisioning profile: AltStore подписывает
его при установке. Файлов `.env` и внешних `ffmpeg`/`ffprobe` внутри нет.
