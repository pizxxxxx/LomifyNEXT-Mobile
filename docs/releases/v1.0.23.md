# LomifyNEXT Mobile 1.0.23

Сборка от 2 октября 2026 года, ветка `ios`.

- Текущая страница получила непрозрачный фон при жесте назад. Предыдущая
  страница видна за её краем; отмена и завершение жеста убирают preview.
- На iOS артист и кнопки шапки прокручиваются в одном WKWebView.scrollView.
  Передача координат нужна при изменениях разметки и коротких переходах;
  обычная корневая прокрутка не пересчитывает расположение через JS.
- Плеер открывается цельной панелью снизу. Большая обложка приближается и
  превращается в фон текста песни; обратный переход возвращает её. Движение
  учитывает настройки анимаций. UIKit playback использует plain-кнопки,
  цельные SF Symbols и согласованные размеры, без большого цветного круга.
- «О треке» доступно через меню трека в списках и плеере. Показывает источник,
  альбом, жанры, дату выпуска/публикации, длительность, лейбл, BPM и ISRC, когда
  сведения доступны. Общие прослушивания/лайки SoundCloud и личные прослушивания
  Lomify подписаны отдельно. Яндекс не передаёт общую статистику трека. Информация
  запрашивается при открытии карточки; при отказе сети остаются сохранённые данные.

Проверки: Svelte/TypeScript — 0 ошибок/предупреждений; навигация, отмена жестов,
modal/idle, долговременное хранение импорта, волна и метаданные проходят.
600 корневых scroll-событий дают 0 чтений геометрии и сообщений координат.
WebKit: 402×874, 320×568, 874×402, обложка ↔ текст и повторное переключение;
ширина не расширяется. При прокрутке артиста мини-плеер закреплён.
