# LomifyNEXT Mobile 1.0.36 — Android и iOS

- Исправлено резкое закрытие полноэкранного плеера после короткого броска пальцем вниз. Вместо конкурирующих анимаций одно движение продолжает плеер из положения под пальцем, учитывает скорость отпускания и плавно тормозит у края экрана.
- Инерция берётся из нескольких последних событий жеста. Если задержать палец после короткого свайпа, плеер возвращается обратно. Системная отмена и потеря захвата указателя также возвращают плеер.
- Длительность обычного закрытия нажатием сохранена. Прокрутка текста, кнопки управления и настройка уменьшения движения остаются доступны.

**Android:** `LomifyNEXT-1.0.36-arm64.apk`, Android 8+, ARM64, прежний ключ подписи.

**iPhone:** `LomifyNEXT-1.0.36.ipa`, iOS 15+, ARM64. Установка через AltStore Classic → My Apps → «+» с тем же Apple ID. Для обновления выберите новую IPA; Refresh All продлевает подпись установленной версии.

Проверены сборки, TypeScript/Svelte, жесты, отмена, траектория и передача кнопок UIKit на поверхность WebKit во время движения. На стенде WebKit с шириной 320 px короткий бросок на 80 px продолжался одним выходом на оставшиеся 616 px за 440 мс. На физическом iPhone новая анимация пока не проверена.
