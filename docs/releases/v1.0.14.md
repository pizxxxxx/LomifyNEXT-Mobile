# LomifyNEXT Mobile 1.0.14

Изменения после 1.0.13.

- Двусторонняя синхронизация своих плейлистов Яндекс Музыки: название, состав и порядок треков.
- Общие плейлисты на телефоне и ПК через один аккаунт Яндекса.
- Кнопка «Связать с Яндексом» в местном плейлисте. Новые подборки закрытые, поддерживаются треки Яндекс Музыки.
- Автоматическое обновление публичных плейлистов SoundCloud. Местные изменения сохраняются в Lomify; запись в SoundCloud по публичному профилю недоступна.
- Сохранение правок без интернета, повторная сверка после восстановления сети и выбор версии при конфликте названий или порядка.
- Неполный ответ сервиса и повторный импорт больше не заменяют ожидающие отправки правки.
- Синхронизацию можно выключить целиком или приостановить для отдельного плейлиста. Скрытие плейлиста из Lomify не удаляет его в сервисе.

Как включить:

1. На телефоне открой «Настройки», подключённый Яндекс и включи «Синхронизация плейлистов».
2. На ПК открой «Настройки», раздел «Музыка», подключи тот же аккаунт и включи такой же переключатель.
3. Для отправки новой местной подборки открой её в медиатеке и нажми «Связать с Яндексом».

Для SoundCloud включи обновление плейлистов у одинакового публичного профиля на обоих устройствах.

APK для Android 8 и новее, ARM64. Подписан прежним ключом для обновления поверх 1.0.13.
