# LomifyNEXT Mobile 1.0.31 — Android и iOS

Исправлено обнаружение обновлений после объединения релизов. Кнопка
«Проверить обновление» в установленной iOS 1.0.25–1.0.27 теперь открывает
этот общий релиз напрямую. Раньше она пропускала 1.0.29–1.0.30 и отправляла
на старую страницу 1.0.27.

APK и IPA по-прежнему находятся вместе. Префикс `ios-v` в адресе страницы
сохраняет совместимость со старой кнопкой iPhone; Android выбирает свой APK
по имени файла. Дизайн «Моей Волны» из 1.0.30 и исправления звонков из
1.0.29 включены.

**Android:** скачайте `LomifyNEXT-1.0.31-arm64.apk` и откройте на телефоне.
Прежний ключ подписи сохранён: удалять приложение перед обновлением не нужно.
Нужен ARM64-телефон с Android 8 или новее. Ранний `1.0.28-arm64-test.apk`
с другим сертификатом остаётся отдельной тестовой установкой.

**iPhone:** скачайте `LomifyNEXT-1.0.31.ipa`, сохраните в «Файлы» и выберите
AltStore Classic → My Apps → «+» с тем же Apple ID, поверх прежней версии.
IPA собрана для устройства, минимум iOS 15; AltStore подпишет её вашей
учётной записью. Refresh All продлевает подпись установленного приложения;
новую версию нужно выбрать через «+».

В релизе находятся APK, IPA и `SHA256SUMS.txt`. Проверены выбор релиза
неизменённым кодом iOS 1.0.27 и текущим кодом обеих платформ, Svelte/TypeScript,
production-сборки, прежний сертификат APK и версии упакованных файлов.
Новая версия на физическом телефоне ещё не проверена.
