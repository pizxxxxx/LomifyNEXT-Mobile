# LomifyNEXT Mobile 1.0.18

- Мобильные настройки переработаны: компактные группы «Музыка», «Интерфейс»
  и «Приложение». Подробные параметры открываются отдельными экранами.
- Убраны декоративные градиенты и тени, уменьшены скругления, иконки стали
  спокойнее. Подписи короче, пояснения о трафике и заряде сохранены.
- Все прежние параметры, подключение Яндекса и SoundCloud, импорт и
  синхронизация доступны на iOS и Android. Импорт продолжает работать при
  переходе к другому экрану настроек.
- Версия сразу видна вверху. Каждая новая выдаваемая сборка получает новую
  видимую версию; команда `npm run version:next` повышает все номера вместе.
- В разделе обновлений iPhone объясняется установка через AltStore.

Версия npm/Cargo/Tauri/интерфейса: 1.0.18. iOS build: 10011.
Android versionCode: 9010011. Изменения локальны в ветке `ios`, без публикации
на GitHub.

Проверка реального компонента в WebKit: девять экранов на 320×568, 390×844 и
812×375, затем все девять с крупным текстом на 320×568. В 36 случаях нет
горизонтального переполнения. Проверены возврат, сохранение переключателя
после перезапуска, переход к Яндексу по запросу, длинное имя, пустая и
подключённая карточка SoundCloud с тестовыми данными, локальная ошибка формы
и открытие раздела клавиатурой. Настоящие аккаунты в проверке не использовались.
Проверка VoiceOver, реального 200% zoom и физических телефонов не выполнена.

IPA для AltStore: `src-tauri/target/ios-dist/LomifyNEXT-1.0.18.ipa`.
Android release APK без подписи:
`src-tauri/target/android-dist/LomifyNEXT-1.0.18-arm64-unsigned.apk`.

Обновление Android поверх опубликованной 1.0.16 по-прежнему требует её ключ
подписи. Старый ключ ещё не предоставлен; debug-подпись этого Mac отличается.
Не удаляйте установленное приложение ради несовпадающей подписи.
