# Android 1.0.28 beta

**Для обновления старой GitHub-версии скачивайте
`LomifyNEXT-1.0.28-arm64.apk`.** Он подписан прежним ключом Windows:
сертификат совпадает с Android 1.0.16, versionCode увеличен. Обновление
устанавливается поверх прежней версии с сохранением данных приложения;
удалять старую установку не нужно.

Общий мобильный интерфейс соответствует iOS 1.0.27: обновлённые настройки,
жесты назад и сворачивания, переходы обложек плейлистов и любимых,
видео под текстом, независимые эдлибы, сведения о треке и автозапуск волны.
UIKit остаётся платформенной частью iOS; Android использует свои кнопки
в общем слое страницы и собственное системное управление.

В Android добавлены нативные next/previous для подготовленных фоновых
треков и сохранение паузы при отключении наушников во время загрузки.
Возврат из фона сверяет состояние аудиодвижка. Лимит фоновой подготовки —
предыдущий и до двух следующих источников; существующие ограничения
Android-декодера и внешних музыкальных сервисов сохранены.

VersionCode 9010021, ARM64, минимум API 26. Изменения находятся в
`main`; iOS 1.0.27 в ветке `ios` и её IPA-релиз не меняются.
Сборка оптимизированная, без Vite и подключения к Mac.

Основной APK доступен в Assets ниже и выбирается проверкой обновлений
в 1.0.16. Сохранённый ранний `LomifyNEXT-1.0.28-arm64-test.apk` имеет
другой сертификат Mac и не обновляет старую GitHub-версию. Он подходит
только для установки с тем же тестовым ключом либо первой установки;
из автоматического выбора исключён по суффиксу `-test`.

SHA-256 основного APK: `836e9a3a3a70d150af0476a83734a457400f5a590f5ff995011f69fbfc495526`.
Сертификат SHA-256: `05646e3ba6891a351bd5b4afe58d66a590ad673819fb4a24e580ed81c67f6dad`.
Checksum основного APK также приложен в `SHA256SUMS-original-key.txt`.

Проверены сборка ARM64, подпись APK, выравнивание для страниц 16 КиБ,
тесты интерфейса и нативной фоновой очереди. После смены подписи проверено
неизменное содержимое всех 960 записей APK. Проверки на физическом
Android-телефоне, обновления установленной 1.0.16, Bluetooth, температуры
и частоты кадров ещё не выполнены.
