# Android 1.0.28 beta

**Тестовая подпись Mac. Этот APK не установится поверх опубликованной
Android 1.0.16 с другим сертификатом.** Подходит для первой установки
или обновления версии, подписанной тем же ключом Mac. Данные старой
установки при отклонении обновления сохраняются; приложение не удаляйте
ради проверки. Если самостоятельно удалить его, локальные данные
приложения будут потеряны.

Общий мобильный интерфейс соответствует iOS 1.0.27: обновлённые настройки,
жесты назад и сворачивания, переходы обложек плейлистов и любимых,
видео под текстом, независимые эдлибы, сведения о треке и автозапуск волны.
UIKit остаётся платформенной частью iOS; Android использует свои кнопки
в общем слое страницы и собственное системное управление.

В Android добавлены нативные next/previous для подготовленных фоновых
треков и сохранение паузы при отключении наушников во время загрузки.
Возврат из фона сверяет состояние аудиодвижка. Лимит фоновой подготовки —
предыдущий и до двух следующих источников; существующие ограничения
Android-декодера и внешних музыкальных сервисов сохранены.

VersionCode 9010021, ARM64, минимум API 26. Изменения находятся в
`main`; iOS 1.0.27 в ветке `ios` и её IPA-релиз не меняются.
Сборка оптимизированная, без Vite и подключения к Mac.

Скачайте `LomifyNEXT-1.0.28-arm64-test.apk` из Assets ниже.
Файл с суффиксом `-test` не предлагается старой Android-версии как
автоматическое обновление, чтобы не предлагать несовместимую подпись.
Обычный режим обновлений требует прежнего ключа.

SHA-256 APK: `5c4534ff71608edc52c188a969c3c195f15fbbb3f471e4c108e1678974b71051`.
Сертификат SHA-256: `e1f2ea2102a135d60e85cf9d80f6cbdc18ad817d3027c96f1140d9f0e5ee9be8`.

Проверены сборка ARM64, подпись APK, выравнивание для страниц 16 КиБ,
тесты интерфейса и нативной фоновой очереди. Проверки на физическом
Android-телефоне, Bluetooth, температуры и частоты кадров ещё не выполнены.
