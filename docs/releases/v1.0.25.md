# LomifyNEXT iOS 1.0.25 beta

2 октября 2026 года, ветка `ios`, iOS build 10018.

В «Настройки → Обновления» на iPhone добавлена кнопка
**«Проверить обновление»**. По нажатию она запрашивает опубликованные релизы
этого репозитория и открывает в браузере страницу самого нового iOS-релиза
с прикреплённым IPA, включая beta. Android-релизы, черновики и релизы без IPA
пропускаются: общая ссылка GitHub `/releases/latest` остаётся за Android.

Проверка выполняется по нажатию, без фонового опроса и без кэша ответа.
Во время запроса кнопка показывает «Проверяем…» и не допускает повторных
нажатий. При отказе сети, лимите GitHub или отсутствии IPA появляется
сообщение; кнопку можно нажать снова или открыть «Все релизы GitHub».
Ожидание ответа ограничено десятью секундами.

Установка новой IPA остаётся через AltStore Classic с тем же Apple ID поверх
прежней версии. Кнопка не устанавливает IPA и не продлевает подпись.
[Инструкция AltStore](../IOS_ALTSTORE.md).

Анимации из 1.0.24 сохранены: переход обложки в текст и обратно длится
620 мс, первый монтаж текста отложен до окончания движения панели,
а готовый текст не пересоздаётся при повторном переключении.
[Проверки анимаций и ограничения](../IOS_FEEDBACK_1.0.24.md).

Проверки: Svelte/TypeScript — 0 ошибок и предупреждений. Сценарии
выбора Android/iOS-релиза, фильтрации IPA, нативного открытия браузера,
ошибки лимита GitHub и неверного ответа проходят. Проверка движения из
1.0.24 также проходит.

WebKit: кнопка показала состояние ожидания и открыла реальный iOS-релиз
1.0.24, последний опубликованный на момент проверки. Экран проверен при
402×874 и 320×568 без горизонтального переполнения. Открытие Safari на
физическом iPhone после обновления отдельно не подтверждено.

Device IPA для ARM64 iPhone успешно собрана под Xcode 27. Версия 1.0.25,
номер сборки 10018, bundle ID `io.github.pizxxxxx.lomifynext.mobile`.
Новая кнопка, выбор iOS-релиза и сохранённый переход 620 мс подтверждены
по байтам ассетов внутри нативного бинарника.

IPA: `src-tauri/target/ios-dist/LomifyNEXT-1.0.25.ipa`, 21 699 384 байт.
SHA-256: `61feac2443545e135cc0f4dc22c27acff8aa89216684552868ec6011079fe6ff`.
Без личной подписи; AltStore подписывает архив при установке.

Android-проверка обновлений не изменена. Публикация — отдельный iOS
prerelease с IPA, без назначения Latest. `main` и Android-релиз остаются
прежними; `.env` и личные ключи в публикацию не входят.

[Релиз ios-v1.0.25](https://github.com/pizxxxxx/LomifyNEXT-Mobile/releases/tag/ios-v1.0.25).
