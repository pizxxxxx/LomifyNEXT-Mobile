# LomifyNEXT Mobile 1.0.33 — Android и iOS

- При запуске на iPhone и Android появляется напоминание, если вышла более новая сборка своей платформы. «Позже» откладывает сообщение до следующего запуска; обновление остаётся в настройках.
- Исправлен запуск после выбора трека и «Моей Волны»: замена предыдущего источника больше не включает ручную паузу. Защита паузы при звонке и отключении наушников сохранена.
- Значки полного плеера стали одинаковыми и компактными в обычном режиме и с текстом. Убрана смена SVG на более крупные нативные значки после перехода.
- При открытии текста приближающаяся обложка плавно становится прозрачной, открывая видеофон. При закрытии возвращается. Убрано анимированное размытие обложки.
- Добавлена системная тактильная отдача при управлении плеером, переключении вкладок и удержании трека; прокрутка и автоматические события её не запускают.
- Исправлен разбор результатов поиска по словам SoundCloud: сервер возвращает `collection` и `has_more`. Поиск работает по внешнему индексу scnative и требует отдельного входа; реальная выдача с аккаунтом пока не проверена.

**Android:** `LomifyNEXT-1.0.33-arm64.apk`, Android 8+, ARM64. Подписан прежним ключом,
устанавливается поверх совместимой старой версии с сохранением данных. Ранняя
тестовая 1.0.28 с другим сертификатом остаётся отдельной установкой.

**iPhone:** `LomifyNEXT-1.0.33.ipa`, iOS 15+, ARM64 для устройства. Сохранить IPA в
«Файлы», затем AltStore Classic → My Apps → «+» с тем же Apple ID. Подпись добавляет
AltStore. Refresh All продлевает подпись установленной версии; новую IPA выбирайте
через «+».

Один общий релиз с APK и IPA. Технический тег `ios-v1.0.33` сохраняет совместимость
кнопки обновления старых iOS 1.0.25–1.0.27. Android выбирает APK с той же страницы.

Проверены типы, регрессионные сценарии, WebKit на 320 px, production-сборки обеих
платформ, подпись APK и содержимое IPA. На физических телефонах версия ещё не
проверена; частота 120 Hz и реальный поиск после входа не заявляются.
