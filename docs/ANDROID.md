# LomifyNEXT для Android

Сборка 1.0.30 обновляет карточку станции на главной:
спокойная общая поверхность, источник и Play. Нажатие открывает станцию
и запускает музыку. [Дизайн и проверки](MOBILE_HOME_WAVE.md).
Общий интерфейс iOS 1.0.27 и Android-управление фоновой очередью сохранены.
[Что перенесено, проверки и подпись](ANDROID_PARITY_1.0.28.md).
[APK на GitHub](https://github.com/pizxxxxx/LomifyNEXT-Mobile/releases/download/v1.0.30/LomifyNEXT-1.0.30-arm64.apk)
подписан прежним ключом Windows: подпись совместима с GitHub-версией 1.0.16.
Возврат к музыке после звонка исправлен на уровне аудиофокуса и нативной
паузы. [Общие релизы](MOBILE_RELEASES.md), [проверки прерывания](MOBILE_INTERRUPTION_1.0.29.md).
Исходники Android находятся в `main`, iOS — в `ios`.

Этот проект отделён от настольного: изменения находятся в `LomifyNEXT-Mobile`.

## Запустить готовую тестовую сборку

1. В Android Studio открой **Tools → Device Manager** и нажми ▶ рядом с Pixel 8.
2. Открой список приложений внутри телефона и нажми **LomifyNEXT**.
   Установленная APK-сборка работает без Vite и без открытого терминала.
3. Внизу: Главная, Поиск, Медиатека, Настройки. Нажми трек, затем мини-плеер,
   чтобы открыть обложку, перемотку и управление воспроизведением.

## Разработка

Android Studio открывает папку `src-tauri/gen/android` внутри мобильного проекта.
Команды ниже запускаются из корня **LomifyNEXT-Mobile**, не из папки Android.

```powershell
npm run tauri android dev
```

Оставь этот терминал открытым, пока пользуешься dev-версией. Для автономной APK:

```powershell
npm run tauri android build -- --debug --target x86_64 --apk
```

Результат: `src-tauri/gen/android/app/build/outputs/apk/universal/debug/app-universal-debug.apk`.
Это сборка для x86_64-эмулятора, не для обычного ARM64-телефона.

## Что входит

- Нижняя навигация, телефонная главная, поиск, любимые треки и сохранённые плейлисты.
- Мини-плеер, экран воспроизведения, перемотка, следующий/предыдущий трек, текст песни.
- Иконка LomifyNEXT, отступы от камеры, системных панелей и клавиатуры.
- Компактные настройки с палитрой и предпросмотром, переключатель плавных переходов.
- Анимации нижнего меню и раскрытия плеера, сохранение вкладок и их прокрутки.
- Громкость регулируется кнопками Android; загрузку трека можно отменить и повторить.
- Отдельная «Моя волна» Яндекса: Главная → Моя волна, плавное открытие, пауза,
  новая подборка и фильтры жанра, языка и вокала из ПК-версии.
- Отдельная волна SoundCloud на главной: начинает с публичных любимых треков и
  дополняет очередь рекомендациями. Для точной подборки сначала импортируй любимое.
- Удерживай обложку или строку трека: откроются превью, лайк, добавление в плейлист
  и скрытие из рекомендаций. Скрытые треки можно вернуть в настройках.
- Создание плейлистов и профиль со статистикой находятся в медиатеке.
- В волне кольца откликаются на звук, а при синхронном тексте показывается текущая
  строка. Кнопка воспроизведения меняет форму при паузе.
- В настройках доступны темы ПК, крупный текст, сдвиг текста, экономия трафика,
  отключение превью и размытия на слабом устройстве.
- Пошаговые инструкции для Яндекса и SoundCloud прямо в настройках.

## Подключить музыку

### Яндекс Музыка

1. Открой **Настройки → Яндекс Музыка → Получить токен**.
   Откроется [сайт проекта MarshalX](https://ym-token.marshal.dev).
2. На сайте выбери **RU**, если нужно, затем **Войти через Яндекс**.
3. Нажми **Открыть страницу Яндекса**. Войди в свой Яндекс ID на странице Яндекса
   и подтверди показанный код. Пароль в Lomify вводить не нужно.
4. Вернись во вкладку MarshalX, дождись блока **Ваш токен готов** и нажми **Скопировать**.
5. Вернись в LomifyNEXT, удержи поле **Токен Яндекс Музыки**, выбери **Вставить**,
   затем **Подключить Яндекс Музыку**. Подтверждение — имя аккаунта и отметка подключения.
6. Нажми **Импортировать любимые треки** или открой **Главная → Моя волна → Слушать волну**.

Это сторонний проект, не официальный сервис Яндекса. Токен — секретный ключ: не
отправляй его в чат и не показывай на скриншотах. Он хранится в данных приложения;
для полного прослушивания нужна подписка Плюс. Если код истёк, начни вход заново.
Другие способы описаны в [репозитории автора](https://github.com/MarshalX/yandex-music-token).

### SoundCloud

1. Открой **Настройки → SoundCloud → Открыть SoundCloud**.
2. На сайте найди свой аккаунт через поиск, открой профиль и скопируй адрес из строки
   браузера. Нужен адрес вида `https://soundcloud.com/никнейм`, не ссылка на трек.
3. Вернись в Lomify, вставь адрес в **Ссылка на профиль или никнейм**, нажми **Найти профиль**.
4. Проверь появившееся имя и нажми **Импортировать медиатеку**. После отчёта об импорте
   нажми **В медиатеку**. Загружаются публичные лайки и до 50 доступных плейлистов.

Пароль и токен SoundCloud не нужны. Изменения не отправляются обратно в SoundCloud.
Если профиль не находится, открой его в браузере, проверь полный адрес и подключение;
при недоступности сервиса проверь VPN. Приватные данные недоступны для импорта.

## Ограничения перед публикацией

- Автоматического возврата токена из браузера пока нет: его нужно вставить вручную.
- Автоскачивание, FFmpeg-конвертация, системный трей, Discord, оконные функции,
  тяжёлые эффекты и десктопные настройки исключены из мобильного интерфейса.
- Android foreground media service и управление с экрана блокировки реализованы.
  Фоновое воспроизведение проверено на эмуляторе; переключение Bluetooth и поведение
  батареи требуют проверки на настоящем телефоне.
- Native Opus не включён; используются поддерживаемые MP3/AAC-потоки.
- Источник иногда отдаёт большой файл целиком, поэтому первое включение может
  занять время даже при исправном приложении. Эмулятор и debug-сборка обычно медленнее
  настоящего телефона; скорость потока зависит и от сети/сервиса.
- Перед Google Play нужны ARM64 release-сборка, подпись, проверка аккаунтов и
  требований магазина. Текущая сборка тестовая, не готовый релиз в магазин.
