# Проверка интерфейса 1.0.32

Область: корневые вкладки, «Главное», поиск (каталог/слова/настроение), история,
меню трека, подбор Яндекса по настроению и запуск/сброс волны по треку. Tauri 2, Svelte 5, TypeScript;
семантические цвета и размеры из `src/mobile.css`, выбранный пользователем шрифт
(Onest по умолчанию). Новые экраны сохраняют существующую тему.
Референсы — предоставленные изображения Яндекс Музыки и SoundCloud Desktop.
AGENTS.md в репозитории и его родительских папках не найден.

UIKit проверен по исходникам и сборкой; живое взаимодействие на физическом iPhone,
VoiceOver/TalkBack и полный обзор остальных экранов не входят в эту проверку.

Все перечисленные изменения выполнены. Открытых HIGH-находок в проверенной области нет.

## Проверено

- `npm run check` с пустым каталогом окружения: 0 errors, 0 warnings.
- `node scripts/mobile-search-test.mjs`: подсказки/история, формы ответов, тексты,
  сервис/сессия, отмена и ограничения, адрес OAuth; раскладка/транслит/опечатки,
  прерывание большой коллекции; изолированная сессия настроения без записи
  настроек основной волны.
- `node scripts/mobile-wave-test.mjs`: seed, очередь, feedback/refill, сброс,
  отмена и запоздавший ответ; плотный аудиосигнал 120 секунд.
- `node scripts/mobile-motion-test.mjs`: порядок отрисовки, направление, inert,
  прерывание и уменьшение движения.
- WebKit: поиск раскрывается и закрывается, Enter выбирает подсказку,
  меню запускает track-станцию ровно один раз, крестик сбрасывает seed.
- WebKit на 320/390 px: ширина документа совпадает с шириной окна; меню и
  фрагменты помещаются. В измеренных переходах вкладок и меню кадры шли с
  интервалом около 16.7–18.5 мс. Тестовый стенд использует вымышленные треки.
- Дополнительно на 320 px: выбор настроения Яндекса и выдача, отсутствие
  названия SoundCloud Desktop в интерфейсе, фрагменты текста поверх обложек.

## Не проверено

- Выдача стороннего сервиса после реального входа, история/станция настоящего
  аккаунта Яндекса, включая подбор настроения. Протокол проверен по первичным
  исходникам и сетевым заглушкам; свободные запросы Люмену не подключены.
- 120 Hz, энергопотребление, аудио и UIKit на физическом телефоне.
- Все цветовые темы и системные программы чтения с экрана.

Approve — для указанной области и проверенного покрытия; экспериментальный внешний
поиск имеет явную зависимость от входа и доступности сервиса.
