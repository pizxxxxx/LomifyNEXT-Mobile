# Аудио на iOS без внешних процессов

iOS использует статически слинкованные библиотеки FFmpeg 8.1 (`libavformat`,
`libavcodec`, `libavutil`, `libswresample`). В приложение не включается исполняемый
файл `ffmpeg`, и обработка аудио не запускает дочерних процессов.

Поддерживаются конвертация в AAC/M4A 256 кбит/с, перепаковка уже готового AAC без
повторного кодирования, перенос `moov` в начало файла (`faststart`), экспорт M4A
с JPEG/PNG/BMP-обложкой и определение длительности. Неподдержанные Symphonia файлы,
включая Ogg/Opus, декодируются теми же библиотеками с поддержкой перемотки.
Обработка файлов выполняется в `spawn_blocking`; готовый результат заменяет файл
атомарным переименованием после успешной записи.

Для iOS настроена категория `AVAudioSessionCategoryPlayback` и фоновый режим
`audio`; общая мобильная очередь может переключать заранее подготовленные треки,
когда WebView приостановлена. Проверка работы при блокировке экрана и после звонка
требует настоящего iPhone. Мост `ios_media` публикует метаданные и обложку в
`MPNowPlayingInfoCenter`, обрабатывает play/pause, переключение и перемотку
из `MPRemoteCommandCenter`. Play/pause и перемотка идут прямо в Rust; следующий
трек использует подготовленную фоновую очередь. Предыдущий трек делегируется
интерфейсу, поэтому переключение назад при приостановленной WebView требует
отдельной проверки. Прерывания аудио и отключение наушников ставят музыку на
паузу; автоматическое возобновление допускается только после рекомендации iOS.

Android и desktop продолжают использовать прежние реализации. Для iOS
`ffmpeg-sidecar` исключён на уровне Cargo, а функции запуска процессов исключены
через `#[cfg(not(target_os = "ios"))]`.

## Воспроизводимая сборка

Из корня репозитория на Mac с Apple Silicon:

```sh
bash scripts/build-ios-ffmpeg.sh aarch64-apple-ios
bash scripts/build-ios-ffmpeg.sh aarch64-apple-ios-sim
```

Скрипт скачивает официальный исходный архив
<https://ffmpeg.org/releases/ffmpeg-8.1.tar.xz>, проверяет SHA-256
`b072aed6871998cce9b36e7774033105ca29e33632be5b6347f3206898e0756a` и компилирует
его инструментами установленного Xcode. Исходники, промежуточные файлы и
библиотеки находятся в игнорируемом Git каталоге `src-tauri/target/ios-ffmpeg`.
Глобальная установка FFmpeg, Homebrew FFmpeg, CMake и NASM не требуются.

Полные параметры `configure` сохранены в `scripts/build-ios-ffmpeg.sh`.
Декодеры и демультиплексоры включены для поддержки входных аудиоформатов;
кодирование выполняет AAC-энкодер. Zlib нужен для PNG-обложек. Сеть, внешние
автоматически обнаруживаемые библиотеки и исполняемые программы отключены в
сборках iOS. Можно ограничить число потоков сборки: `LOMIFY_FFMPEG_JOBS=4`.

`src-tauri/build.rs` подключает библиотеки соответствующего Rust-таргета. Для
отдельного локального каталога библиотек задайте `LOMIFY_IOS_FFMPEG_DIR`.
Библиотеки устройства и симулятора нельзя смешивать: у них разные платформы,
хотя обе сборки используют ARM64.

## Проверка

```sh
python3 scripts/test-ios-audio.py
```

Проверка использует тот же C-мост на macOS: реальные WAV, FLAC, Ogg/Opus,
AAC/M4A и ADTS/AAC, чтение до конца, перемотка, конвертация, длительность,
`faststart`, экспорт PNG-обложки с проверкой неизменности AAC-пакетов,
ошибочные входные данные и экспорт без обложки. Программы FFmpeg для тестовых
образцов собираются только для macOS в локальном каталоге; в IPA они не входят.
Также проверяются JPEG/BMP-обложки и MP3: тестовый MP3 из официального каталога
FFmpeg скачивается в игнорируемый тестовый каталог с проверкой SHA-256.
Эта проверка не заменяет запуск приложения и проверку звука на настоящем iPhone.

## Исходники и лицензия

FFmpeg распространяется по LGPL-2.1-or-later в этой конфигурации: опции GPL и
nonfree не включены. Исходники FFmpeg не изменены. Исходный архив, скрипт сборки
и код моста позволяют воспроизвести библиотеки. Само приложение сохраняет свою
лицензию GPL-3.0-or-later. При распространении IPA приложите этот документ,
текст лицензии FFmpeg и доступ к соответствующим исходникам приложения.

Справочники: [API кодирования и декодирования](https://ffmpeg.org/doxygen/8.1/group__lavc__encdec.html),
[API записи контейнеров](https://ffmpeg.org/doxygen/8.1/group__lavf__encoding.html),
[лицензирование FFmpeg](https://ffmpeg.org/legal.html).
