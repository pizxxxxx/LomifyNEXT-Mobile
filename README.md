# LomifyNEXT Mobile

LomifyNEXT Mobile - музыкальный плеер для Android, который объединяет Яндекс Музыку, SoundCloud и твою медиатеку. Слушай любимые треки, открывай новую музыку и настраивай приложение под себя.

## Что есть в приложении

- Поиск музыки, любимые треки и плейлисты.
- Персональные станции Яндекс Музыки и SoundCloud.
- Скачивание треков для прослушивания без интернета.
- Полноэкранный плеер с обложкой, видеофоном и текстом песни.
- Синхронная подсветка текста по строкам или по буквам.
- Очередь воспроизведения с возможностью поставить выбранный трек следующим.
- Фоновое воспроизведение и управление с экрана блокировки.
- Изменение названий и обложек плейлистов.
- Темы оформления, выбор шрифтов, эквалайзер и экономия трафика.
